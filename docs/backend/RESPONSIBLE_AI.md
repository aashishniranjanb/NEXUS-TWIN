# Responsible AI Framework & Safety Protocols

| Pillar | Implementation |
|---|---|
| **Human-in-the-Loop** | AI generates recommendations; human supervisor holds final approval/override authority. |
| **Evidence Grounding** | Every recommendation is strictly grounded in quantitative 900s Digital Twin simulation deltas. |
| **No Hallucinated Signals** | LLM does not perform math or invent traffic data. |
| **Causal Disclaimers** | System explicitly labels observational pattern deviations (`INCIDENT_LIKE`, `SIGNAL_RELATED`) without claiming unverified physical collision or hardware damage. |
| **Explainability** | Full transparency on observed state, predicted impact, candidate trade-offs, and reasoning. |
